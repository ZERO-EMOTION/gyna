# Gyna

**Persistent Intelligence Trading System for MetaTrader 5**

True Memory. Compounding AI. Never resets.

## Vision
Gyna remembers every trade, every rationale, every outcome. It builds cumulative intelligence over time.

## Features
- Hybrid Python + MT5 architecture
- LangGraph agent with persistent memory
- Vector + Structured memory
- Reflection & self-improvement loop
- Risk management

## Quick Start
1. Clone the repo
2. Copy `.env.example` to `.env` and fill credentials
3. `pip install -r requirements.txt`
4. Run `python main.py`

## Structure
- `mt5_bridge.py` - MT5 connection
- `memory/` - Persistent storage
- `agents/` - LangGraph brain
